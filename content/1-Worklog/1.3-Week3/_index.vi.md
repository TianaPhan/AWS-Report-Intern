### Kết quả đạt được tuần 3:

- Hiểu rõ cách triển khai và vận hành các dịch vụ AWS gồm Amazon EC2, Amazon RDS và Amazon S3 trong môi trường thực tế.
- Tạo và cấu hình thành công EC2 instance, cài đặt web server (Apache, PHP) và truy cập thông qua SSH/Public IP.
- Khởi tạo RDS (MySQL), thiết lập Security Group và kết nối thành công giữa EC2 và RDS.
- Thực hiện import database từ local lên RDS và kiểm tra truy vấn dữ liệu hoạt động ổn định.
- Tạo S3 bucket, upload file và cấu hình quyền truy cập để lưu trữ tài nguyên tĩnh.
- Hiểu được cách các dịch vụ EC2 – RDS – S3 phối hợp trong kiến trúc hệ thống web trên cloud.
- Tích lũy kinh nghiệm thực hành thực tế, sẵn sàng cho việc triển khai project ở các tuần tiếp theo.
