### Week 3 Objectives:

This week focused on hands-on practice with AWS services including EC2, RDS, and S3. The goal was to gain practical experience and understand how these services operate in a real-world environment before starting the project deployment.

### Week 3 Achievements:

- Gain a thorough understanding of how to deploy and operate AWS services, including Amazon EC2, Amazon RDS, and Amazon S3, in a real-world environment.
- Successfully create and configure an EC2 instance, install a web server (Apache, PHP), and access it via SSH/Public IP.
- Initialize an RDS (MySQL), set up a Security Group, and successfully establish a connection between EC2 and RDS.
- Import a database from your local machine to RDS and verify stable data query performance.
- Create an S3 bucket, upload files, and configure access permissions to store static resources.
- Understand how EC2, RDS, and S3 services work together in a cloud-based web system architecture.
- Accumulate practical experience, preparing for project deployment in the coming weeks.
