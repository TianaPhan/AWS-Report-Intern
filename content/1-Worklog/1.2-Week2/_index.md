### Week 2 Objectives:

* Connect and get acquainted with members of First Cloud Journey.
* Understand basic AWS services, how to use the console & CLI.
* Focus on learning about AWS services related to storage, databases, and monitoring, such as S3, RDS, and CloudWatch.

### Week 2 Achievements:

* Understand the operation and roles of AWS services including Amazon S3, Amazon RDS, and Amazon CloudWatch within the architecture.
* Learn how to store static data on S3, manage the database system with RDS, and monitor the system using CloudWatch.
* Practice creating and configuring the services: create an S3 container, initiate RDS instance creation, and view logs/metrics on CloudWatch.
* Understand the relationship between services in the actual deployment development model (EC2 – RDS – S3 – CloudWatch).
